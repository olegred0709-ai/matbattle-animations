# Анимации стикменов «Матбатла»

Галерея анимаций персонажа-стикмена для мини-приложения «Матбатл» в MAX: вход, загрузка,
батл, итоги матча, профиль. Конструктор персонажа и оценки 👍/👎 с комментариями.

Страница: https://olegred0709-ai.github.io/matbattle-animations/

Оценки хранятся в браузере; кнопка «Скопировать мои оценки» собирает их текстом для чата команды.
